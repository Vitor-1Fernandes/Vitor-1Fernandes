## 🚀 Projetos em destaque

### 🧠 SYND: Inteligência Conversacional com IA
> Transforma o áudio de reuniões comerciais em dados e insights.

Captação via sensor → transcrição → análise por IA → dashboard para gestores e vendedores.
Atuei na maior parte do desenvolvimento: backend em **FastAPI**, tratamento das transcrições com **Pandas**, integração com a **API do Gemini** e conexão fim a fim com o front em **Next.js/TypeScript**.
🔗 [synd-iot.vercel.app](https://synd-iot.vercel.app)

### 🌍 Análise de Dados Socioeconômicos Globais
> Python consumindo as APIs da Wikipedia e do Wikidata em tempo real.

Coleta e trata indicadores de vários países (PIB, IDH, desemprego, idade de aposentadoria, população), calcula média, média ponderada, variância e amplitude, e gera gráficos comparativos com **Matplotlib**, usando `requests` e `numpy`.

### 🏟️ Vendors Conference e AutoCred
Automações em **Python, Pandas, Selenium e Tkinter** criadas no trabalho para resolver gargalos operacionais reais (detalhes acima).
